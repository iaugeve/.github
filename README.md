# .github de Auge

Este repositorio no tiene código de producto. Guarda lo que GitHub comparte con todos los repositorios de la organización `iaugeve`:

| Archivo | Qué hace |
| --- | --- |
| `profile/README.md` | La portada pública de [github.com/iaugeve](https://github.com/iaugeve) |
| `CONTRIBUTING.md` | Cómo trabajamos: ramas, commits, Pull Requests y versiones |
| `PULL_REQUEST_TEMPLATE.md` | La plantilla que aparece al abrir un Pull Request |
| `ISSUE_TEMPLATE/` | Formularios para reportar un error, proponer una mejora o anotar una tarea |
| `SECURITY.md` | Cómo reportar un problema de seguridad |
| `CODE_OF_CONDUCT.md` | Cómo nos tratamos |
| `SUPPORT.md` | A dónde escribe un cliente que necesita ayuda |
| `workflow-templates/` | CI listos para elegir en la pestaña Actions de cada repo (Next.js, Laravel y Astro) |
| `assets/` | Logo y los íconos de los productos que usa el perfil |
| `plantillas-repo/` | Archivos para copiar a mano en cada repo: `dependabot.yml`, `CODEOWNERS`, `.editorconfig`, `.gitattributes` |

Un repositorio que tenga su propio archivo con el mismo nombre usa el suyo en lugar de este.

## Reglas

- **Este repositorio es público**, porque GitHub solo comparte estos archivos desde un `.github` público. Nada de lo que hay aquí puede llevar claves, puertos, nombres de bases de datos ni información interna.
- Los logos se copian de `redes/logos/` y los íconos de `redes/productos/`, sin modificarlos.
- Cuando se agregue un producto, súmalo a la tabla de `profile/README.md` con su ícono en `assets/productos/`.
