## Cómo trabajamos

- **Pruebas antes que promesas.** Productos funcionando, demos y números reales. Si no se puede mostrar en una demo, no lo prometemos.
- **Hecho para la Venezuela real.** Multimoneda a tasa BCV, pago móvil, WhatsApp y funcionamiento sin conexión.
- **Velocidad con orden.** Entregas por etapas, en días, con una demo al cierre de cada una.
- **Tu código y tus datos son tuyos.** Y el soporte lo da gente que está aquí.
